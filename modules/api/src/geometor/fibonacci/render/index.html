src.geometor.fibonacci.render¶

Publication-grade interactive .euclid-graphic SVG renderer for GEOMETOR Fibonacci.

Generates crisp pixel-space SVGs directly from Model instances while preserving exact SymPy coordinates in metadata attributes and <title> tooltips. Outputs conform simultaneously to:

  1. Standalone SVG viewing (GitHub README.rst, browsers, prefers-color-scheme dark/light palettes via an embedded <style> sheet), and

  2. PHOTON Publish interactive Book Codices (svg.euclid-graphic, #elements, #graphics, #highlights, #points, #labels, #geom-tick-1..3 markers, 3-vertex <path> segments, data-ref, and data-aliases).
